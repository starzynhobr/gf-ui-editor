# GF UI Editor — vault

Comece aqui. Revisão: **24/11/2026**.

## Como funciona

1. **O [roadmap](roadmap.md) diz o que vem e em que ordem.** Cada fase vira uma versão.
2. **O [quadro](backlog.md) diz o que está sendo feito agora.** Item feito sai do quadro e vira linha no [estado atual](status.md).
3. **O código é a verdade** sobre o que existe. O vault planeja; não descreve código que mudou sem conferir.
4. **Decisão nova** → uma linha em [decisões](decisions.md).
5. **Feedback de usuário** → uma nota em `feedback/`, com o que foi pedido e o que virou item do roadmap.
